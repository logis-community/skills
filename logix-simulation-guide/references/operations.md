# 操作步骤与核对方法

适用于客户端 4.1.4-15。执行保存、导入、同步或运行前，确认打开的是目标案例，账号具备当前操作所需权限，仿真服务可用。练习或对照实验使用可编辑的案例副本和独立数据集。[4.1.4-15 发布说明](https://ipa-changelog.vercel.app/a/logix/v-4-1-4-15)

| 目标 | 操作 | 核对结果 |
| --- | --- | --- |
| 打开案例 | 在「案例库」打开现有案例，或用「新建案例」输入名称。需要修改只读内置案例时先复制。用「导入案例」选择案例 ZIP，根据包内文件查阅[案例包导入](simulation-rules.md#案例包导入)。 | 打开导入后的案例，核对转换提示、场景、逻辑流程及关联的数据集。 |
| 搭建场景 | 从左侧「场景组件」拖入「场景搭建」画布，点选节点，在右侧属性面板配置名称、尺寸和适用的连接点。需要界面定位时用「工作台引导」。 | 检查节点位置、物理尺寸及连接端点。带网格或货架的案例还应检查[建模规则](simulation-rules.md#逻辑与场景)。 |
| 编排流程 | 从「逻辑节点」选择组件，在「逻辑编排」画布配置属性，按任务执行方向连接。使用画布标题栏的「新建流程」，通过下拉框确认正在编辑的流程。 | 核对流程、节点顺序、起止角色与场景引用。 |
| 配置业务数据 | 在「案例设置」选择数据集后点「保存设置」。从工作台「数据集」可查看订单表、储位表和规格表，未关联时可用「创建空数据集」。首次同步货架储位前，先导出并核对目标数据集的现有储位数据。按[储位与导入](simulation-rules.md#储位与导入)核对版本、同步提示及 Excel 工作表和列映射。 | 导入后核对各表处理行数及失败行。回到「案例设置」确认本次运行关联的数据集。 |
| 保存并运行 | 在「案例设置」核对「仿真时长限制」，在工作台点「保存案例」并检查反馈。点击「运行案例」，从顶栏状态圆点查看仿真进度和实时事件。需要终止当前运行时用工具栏的「停止」。 | 「保存成功」后仍应处理与运行相关的警告。运行时核对进度和事件，结束后确认本次运行的完成或失败状态。 |
| 查看结果 | 在仿真进度面板使用「打开报告」。仿真结束后按可用状态打开「2D播放」或「3D播放」。报告无法打开时先记录提示，并检查仿真后端服务地址和连通性。 | 核对报告与回放属于同一次运行。出现「暂无仿真结果，无法3D播放」时先核对该次运行是否生成可用结果。 |

## 复查案例

1. 从可运行的案例副本和少量业务数据开始。记录客户端版本、案例、数据集、仿真时长限制和这次要核对的业务结果。修改布局或批量导入前，可用「下载案例」保留案例 ZIP，用数据集导出保留受影响的表。
2. 将保存警告定位到具体节点或连线。验证关联数据、流程方向和关键作业点后开始运行。失败时保留原始提示和运行标识，核对最后一条相关事件，再决定修改输入还是检查服务。
3. 比较方案时保留基线案例及其数据。每次只修改一个待验证因素，按相同输入口径和时长运行，记录两次运行在同一指标上的差异。

## 验证范围

操作路径和界面文案已按 4.1.4-15 发布源码核对。桌面客户端端到端实跑及报告数值待验证。实跑需要目标客户端和后端构建号、可复跑的脱敏案例 ZIP、配套 Excel 和预期报告。核对吞吐量、利用率等数值时，使用对应版本的字段定义、单位、统计时间窗口和起止条件。
