# Logix 单机离线证书签发

使用 Keygen 为已收集设备标识的用户生成机器绑定的 `.lic`，并维护原台账。默认按当前 Logix 的“订阅版 · 1 年”策略、单机一证处理；用户明确指定其他条款时，以该条款为准。签发和修改台账是实际写操作，先确认当前任务已有授权；不要因为使用了本 Skill 就自行发证或修改策略。

## 签发前

1. 读取工作簿全部相关工作表，确认姓名或用户名、设备标识、发放标记及表内期限字段的含义。只处理明确未发放且字段完整的行；64 位小写十六进制设备指纹必须来自 Logix 客户端。遇到多个候选工作簿、模糊状态、重复指纹、同名文件或相互冲突的期限，先核实，不猜测。
2. 从当前部署配置和 Keygen 查询账户、Logix 产品、目标 policy 及其 `maxMachines`、`duration`。核对用户名应写入许可证 `name`，目标 policy 确实属于 Logix 且只允许一台机器。若要求“父许可证无到期日”同时又要求有限期订阅 policy，先澄清最终条款。
3. 按设备指纹查询已有 machine、父 license 和现存证书，检查完整分页。文件存在或创建请求结果不明时，先核对服务端状态，避免重复签发。为本次运行保留私有的行号到许可证、机器及文件的映射；不要把密钥、指纹、证书内容或个人信息写入普通日志、仓库或结果正文。

## 逐行签发

1. 复用符合**用户名、策略、产品、期限和设备绑定**要求的现有记录；不符合时创建新 license。新 license 的 `name` 为台账用户名，policy 为已核对的目标策略。创建后读取实际 `expiry`，确认父许可证的期限符合用户要求。
2. 用该 license 为设备指纹激活 machine，再从 machine checkout 未加密的 `MACHINE FILE`，请求中包含 `encrypt: false` 和 `include: ["license"]`。一年文件的 Keygen CE 1.7.2 参数与时间陷阱见 [Keygen 机器文件细节](references/keygen-machine-file.md)；始终以签出文件的实际日期验证期限。
3. 使用当前账户公钥验 Ed25519 签名，并核对文件类型、指纹、机器与父许可证 ID、用户名、policy、产品、`ACTIVE` 状态、单机额度、父许可证及文件各自的到期日。有效截止时间是两种到期日中较早者。把证书写入私有目录后再从磁盘读取并复验。文件名按任务要求使用 `<用户名>离线证书.lic`；同名冲突时用稳定行号或设备标识摘要区分并记录映射。
4. **只有该行证书创建、导出、复验成功后**，才把该行标记为已发放。保留工作簿其他值、公式、格式与对象；不要因导出工具重写样式而交付改变范围扩大的文件。失败或模糊的行保持原标记。校验最终工作簿及每份文件，并按用户指定的受控渠道交付；报告成功、失败、跳过数量与原因，不在正文粘贴许可证或个人信息。

## 重签或改策略

现有 license 的 policy 可能不允许直接改绑。先创建符合新策略和用户名的替代 license、machine 与证书，并完成上述验证；之后再停用旧 license。保留旧记录以便追溯，不在结果不明时反复创建。**停用服务端许可证无法即时撤销已经分发的离线签名文件**；明确指出旧文件被新文件替代，已分发副本也需要更换。

具体 Keygen 请求、期限核对和文件结构见 [references/keygen-machine-file.md](references/keygen-machine-file.md)。
